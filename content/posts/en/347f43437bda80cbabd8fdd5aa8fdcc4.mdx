This post is part of the 'Let's use WebView in React Native like Native!' series (3): Implementing pull to refresh in WebView!

As introduced in the previous issue overview post, the WebView does not inherently provide a pull-to-refresh feature.

![image.gif](https://velog.velcdn.com/images/yeojinseuk/post/26d8f6f8-084b-4f92-9450-f51ba039bb08/image.gif)

## Solution

To enable pull to refresh, I tested and applied three methods.

### 1. Using the `pullToRefreshEnabled` option

This is the easiest method.
It's a feature natively provided by `WebView`.

```plain text
<WebView
    pullToRefreshEnabled
    source={{ uri: `${URL}${path}` }}
  />
```

![image.gif](https://velog.velcdn.com/images/yeojinseuk/post/828203ad-ef2a-4d95-9413-d7757f75cdc5/image.gif)

While the pull-to-refresh event itself works, it triggers an event that reloads the entire WebView.

If you pull to refresh the WebView screen in the Toss app, it behaves as shown above.

However, this differs from how pull to refresh typically operates in native apps.
In native apps, the refresh event is controlled via the pull event.

1. Communicating with the pull to refresh event in the React Native app

![image.gif](https://velog.velcdn.com/images/yeojinseuk/post/4876f57c-8cbe-430e-82ba-2eeb990e2383/image.gif)

This method involves structuring the `WebView` within a `ScrollView` to trigger scroll events, which then send a refresh event. The video above shows the refresh function operating for 2 seconds.

The code is as follows.

- Common Event Schema

```typescript
const webViewEventSchema = z.object({
  type: z.enum(WEBVIEW_EVENT_LIST),
  data: z.any().optional(),
});
```

- React Native

- web

```typescript
React.useEffect(() => {
    if (window.ReactNativeWebView == null) {
      return;
    }

    const handleRefresh = (e: Event) => {
      if (e instanceof MessageEvent) {
        const event = webViewEventSchema.safeParse(JSON.parse(e.data));

        try {
          if (event.error) {
            throw new Error('Undefined event type');
          }

          if (event.data.type !== 'ON_REFRESH') {
            return;
          }

          if (!onRefresh) {
            window.ReactNativeWebView?.postMessage(
              JSON.stringify({
                type: WEBVIEW_EVENT_TYPE.ON_FINISHED_REFRESH,
              }),
            );
            return;
          }

          return onRefresh().then(() => {
            window.ReactNativeWebView?.postMessage(
              JSON.stringify({
                type: WEBVIEW_EVENT_TYPE.ON_FINISHED_REFRESH,
              }),
            );
          });
        } catch (err) {
          acError(`WebView refresh communication failed ${err}`, err);
          return;
        }
      }
    };

    document.addEventListener('message', handleRefresh);
    window.addEventListener('message', handleRefresh);

    return () => {
      document.removeEventListener('message', handleRefresh);
      window.removeEventListener('message', handleRefresh);
    };
  }, [onRefresh]);
```

The flow is as follows.

1. `ScrollView` `RefreshEvent` occurs
2. Send refresh event `postMessage` to Web
3. Web receives the message, validates the event with the `zod` schema, then receives the `ON_REFRESH` event
4. When the refresh event occurs, execute the defined refresh event and send the `ON_FINISHED_REFRESH` event to the App
5. App receives the `ON_FINISHED_REFRESH` event after validating it with the `zod` schema
6. Terminate refresh UI

It now looks even more like a native app.

1. Implement pull to refresh directly in the web.

In my opinion, this method provides the most app-like WebView experience.
It also has the advantage of displaying a consistent UI across both Android and iOS.

The implementation method is as follows.

1. Create a scroll container with a loading component and scrollable content area inside, then transform the container by the height of the loading UI.

```typescript
const REFRESH_SCROLL_POSITION = 64;

  ...

  const contentContainerRef = React.useRef<HTMLDivElement>(null);

   return (
    <Stack
      flex={1}
      sx={{ overflowY: 'scroll' }}
    >
      <Stack ref={contentContainerRef} sx={{ transform: `translateY(-${REFRESH_SCROLL_POSITION}px)` }} pt={2} gap={1}>
        <Stack width={'100%'} height={REFRESH_SCROLL_POSITION} justifyContent={'center'} alignItems={'center'}>
          <LoadingComponent/>
        </Stack>
        <Stack flex={1}>{/* Scrollable content */}</Stack>
      </Stack>
    </Stack>
   )
```

1. Get the y-position value when the screen is first touched.

```typescript
const contentContainerRef = React.useRef<HTMLDivElement>(null);

  function handleTouchStart(event: React.TouchEvent<HTMLDivElement>) {
    touchYPositionRef.current = event.touches.item(0).clientY;
  }
```

1. As you move while touching, calculate the pull distance as the difference between the current y-value and the initial touch y-value.

```typescript
function handleTouchMove(event: React.TouchEvent<HTMLDivElement>) {
    const moveY = event.touches.item(0).clientY;
    const pullDistance = moveY - touchYPositionRef.current; // pull distance
  }
```

1. Check if the pull distance is greater than a specific value and if the `scrollTop` of the scrolling container is less than or equal to 0. If the conditions are met, change the refresh request flag to `true` and reset the container's position to make the loading UI visible.

```typescript
const contentContainerRef = React.useRef<HTMLDivElement>(null);
  const refreshingRef = React.useRef(false);
  const touchYPositionRef = React.useRef(0);

  function handleTouchMove(event: React.TouchEvent<HTMLDivElement>) {
    if (!contentContainerRef.current) {
      return;
    }

    const moveY = event.touches.item(0).clientY;
    const pullDistance = moveY - touchYPositionRef.current;

    if (pullDistance > 120 && event.currentTarget.scrollTop <= 0) {
      contentContainerRef.current.style.transform = 'translate(0, 0px)';
      contentContainerRef.current.style.transition = '0.3s';

      refreshingRef.current = true;
    }
  }
```

1. When the touch ends, if the refresh event flag is `true`, execute the refresh event. Once the event is complete, transform the loading UI back to its hidden state.

```typescript
function handleTouchEnd() {
    if (refreshingRef.current) {
      return onRefresh().finally(() => {
        if (contentContainerRef.current) {
          contentContainerRef.current.style.transform = `translate(0,-${REFRESH_SCROLL_POSITION}px)`;
          contentContainerRef.current.style.transition = '0.3s';
          refreshingRef.current = false;
        }
      });
    }
  }
```

The complete code is as follows.
To use it commonly, I structured it as a separate `PTRContainer` component.

- PTRContainer

```typescript
const REFRESH_SCROLL_POSITION = 64;

/**
 * Pull to refresh control container
 **/
export function PTRContainer({ children, onRefresh }: { children: React.ReactNode; onRefresh: () => Promise<any> }) {
  const contentContainerRef = React.useRef<HTMLDivElement>(null);
  const refreshingRef = React.useRef(false);
  const touchYPositionRef = React.useRef(0);

  function handleTouchStart(event: React.TouchEvent<HTMLDivElement>) {
    touchYPositionRef.current = event.touches.item(0).clientY;
  }

  function handleTouchMove(event: React.TouchEvent<HTMLDivElement>) {
    if (!contentContainerRef.current) {
      return;
    }

    const moveY = event.touches.item(0).clientY;
    const pullDistance = moveY - touchYPositionRef.current;

    if (pullDistance > 120 && event.currentTarget.scrollTop < 0) {
      contentContainerRef.current.style.transform = 'translate(0, 0px)';
      contentContainerRef.current.style.transition = '0.3s';

      refreshingRef.current = true; // refresh true
    }
  }

  function handleTouchEnd() {
    if (refreshingRef.current) {
      return onRefresh().finally(() => {
        if (contentContainerRef.current) {
          contentContainerRef.current.style.transform = `translate(0,-${REFRESH_SCROLL_POSITION}px)`;
          contentContainerRef.current.style.transition = '0.3s';
          refreshingRef.current = false;
        }
      });
    }
  }

  return (
    <Stack
      flex={1}
      sx={{
        overflowY: 'scroll',
        '&::-webkit-scrollbar': {
          display: 'none',
        },
        '-ms-overflow-style': 'none',
      }}
      onTouchStart={handleTouchStart}
      onTouchMove={handleTouchMove}
      onTouchEnd={handleTouchEnd}
    >
      <Stack ref={contentContainerRef} sx={{ transform: `translateY(-${REFRESH_SCROLL_POSITION}px)` }} pt={2} gap={1}>
        <Stack width={'100%'} height={REFRESH_SCROLL_POSITION} justifyContent={'center'} alignItems={'center'}>
          <LoadingComponent/>
        </Stack>
        <Stack flex={1}>{children}</Stack>
      </Stack>
    </Stack>
  );
}
```
